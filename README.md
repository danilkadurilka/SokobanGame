# Sokoban Game - Описание проекта

## Обзор

Проект представляет собой классическую японскую логическую игру "Сокобан" (Sokoban), разработанную на платформе WPF (.NET). Игрок управляет персонажем, который должен толкать ящики на целевые позиции. Проект включает систему рекордов, редактор уровней и базу данных SQL Server для хранения данных.

## Технологический стек

- **Платформа**: WPF (.NET)
- **Язык**: C#
- **База данных**: SQL Server (Entity Framework Core)
- **Архитектура**: MVVM (Model-View-ViewModel)

---

## Структура проекта

### Модели (Models)

#### `Level.cs`
Модель игрового уровня.

**Свойства:**
- `Id` - уникальный идентификатор уровня
- `Name` - название уровня
- `Width` - ширина игрового поля
- `Height` - высота игрового поля
- `MapData` - строковое представление карты уровня
- `IsDefault` - флаг стандартного уровня (нельзя удалить)
- `Records` - коллекция рекордов для этого уровня

**Вспомогательный класс `LevelToDisplay`:**
Используется для отображения уровня со статистикой в окне выбора уровней. Содержит информацию о лучшем результате игрока.

---

#### `Record.cs`
Модель рекорда прохождения уровня.

**Свойства:**
- `Id` - уникальный идентификатор рекорда
- `PlayerName` - имя игрока
- `LevelId` - идентификатор уровня
- `CountMoves` - количество ходов
- `Time` - время прохождения в секундах
- `CompletedAt` - дата и время завершения
- `Level` - навигационное свойство к уровню

---

#### `GameModel.cs`
Модель состояния игрового процесса.

**Свойства:**
- `Width` / `Height` - размеры игрового поля
- `TileMap` - двумерный массив типов тайлов
- `PlayerX` / `PlayerY` - координаты игрока
- `CountMoves` - счетчик ходов
- `StartTime` - время начала игры
- `CurrentTime` - прошедшее время (вычисляемое)

Реализует `INotifyPropertyChanged` для обновления UI.

---

### ViewModels (ViewModel)

#### `BaseVM.cs`
Базовый класс для всех ViewModel, реализующий `INotifyPropertyChanged`.

**Метод:** `OnPropertyChanged()` - уведомление об изменении свойства.

---

#### `GameVM.cs`
Основная ViewModel для игрового процесса.

**Команды:**
- `MoveUpCommand` / `MoveDownCommand` / `MoveLeftCommand` / `MoveRightCommand` - перемещение игрока
- `RestartCommand` - перезапуск уровня
- `BackToMenuCommand` - возврат в главное меню

**Логика:**
- Загрузка уровня из модели
- Обработка движения игрока и толкания ящиков
- Проверка условий победы
- Запись рекордов в базу данных
- Таймер для отслеживания времени прохождения
- Обновление UI через привязки данных

---

#### `LevelEditorVM.cs`
ViewModel для редактора уровней.

**Команды:**
- `NewLevelCommand` - создание нового уровня
- `SaveLevelCommand` - сохранение уровня
- `DeleteLevelCommand` - удаление уровня
- `SetTileCommand` - установка типа тайла
- `BackToMenuCommand` - возврат в меню

**Свойства:**
- `Width` / `Height` - размеры редактируемого поля
- `LevelName` - название уровня
- `TileRows` - коллекция строк тайлов для отображения
- `Levels` - список всех уровней
- `SelectedLevel` - выбранный уровень
- `IsFloorSelected`, `IsWallSelected`, `IsTargetSelected`, `IsBoxSelected`, `IsPlayerSelected` - выбранный инструмент

**Логика:**
- Загрузка и сохранение уровней в БД
- Изменение размера карты с сохранением существующих тайлов
- Валидация карты (наличие игрока)
- Конвертация между представлением тайлов и строковым форматом

---

#### `MainMenuVM.cs`
ViewModel для главного меню.

**Команды:**
- `NewGameCommand` - начать новую игру
- `LevelEditorCommand` - открыть редактор уровней
- `RecordsCommand` - показать таблицу рекордов
- `InstructionsCommand` - показать инструкцию
- `ExitCommand` - выход из приложения

---

#### `RelayCommand.cs`
Реализация интерфейса `ICommand` для связывания UI команд с методами ViewModel.

**Конструктор:**
- `RelayCommand(Action<object> execute, Func<object, bool> canExecute = null)`

**Методы:**
- `CanExecute()` - проверка возможности выполнения
- `Execute()` - выполнение команды

---

#### `TileVM.cs`
ViewModel для отдельной клетки игрового поля.

**Свойства:**
- `TileType` - тип тайла (Wall, Floor, Box, Target, BoxOnTarget, PlayerOnTarget)
- `HasPlayer` - находится ли игрок на этой клетке
- `DisplayType` - вычисляемый тип для отображения
- `TileImage` - изображение для отображения
- `X` / `Y` - координаты клетки

**Логика:**
- Автоматическое определение пути к изображению на основе типа тайла
- Загрузка изображений из папки `/Images`

---

### Views (WPF Windows)

#### `MenuWindow.xaml`
Главное окно приложения. Содержит кнопки для навигации по всем функциям игры.

---

#### `NameInputWindow.xaml`
Окно ввода имени игрока перед началом игры или входом в редактор.

**Параметр:** `isForEditor` - определяет, запускать игру или редактор.

---

#### `LevelSelectionWindow.xaml`
Окно выбора уровня для игры. Отображает список уровней с лучшими результатами текущего игрока.

---

#### `GameWindow.xaml`
Основное игровое окно. Содержит:
- Информация об игроке, ходах и времени
- Игровое поле (ItemsControl с динамическими тайлами)
- Кнопки перезапуска и выхода в меню
- Подсказки по управлению

**Управление:** Стрелки/WASD - движение, R - перезапуск, Esc - выход.

---

#### `LevelEditorWindow.xaml`
Окно редактора уровней. Содержит:
- Список уровней
- Инструменты для рисования (пол, стена, цель, ящик, игрок)
- Параметры размера поля
- Поле для названия уровня

---

#### `RecordsWindow.xaml`
Окно с таблицей рекордов. Группирует результаты по уровням, показывает лучшие прохождения всех игроков.

---

#### `InstructionsWindow.xaml`
Окно с инструкцией по игре. Содержит описание правил, управления и системы рекордов.

---

### База данных (Database)

#### `SokobanDbContext.cs`
Контекст Entity Framework Core для работы с базой данных SQL Server.

**DbSet:**
- `Levels` - уровни
- `Records` - рекорды

**Методы:**
- `EnsureDatabaseCreated()` - создание базы данных и заполнение стандартными уровнями
- `SeedDefaultLevels()` - инициализация 8 стандартных уровней

**Стандартные уровни:**
- 8 предустановленных уровней различной сложности
- Размеры полей от 8x4 до 21x20
- Отмечены флагом `IsDefault = true` (не могут быть удалены)

## Архитектурные особенности

### MVVM паттерн
- **Model** - данные и бизнес-логика (`Level`, `Record`, `GameModel`)
- **View** - XAML разметка окон
- **ViewModel** - связующее звено между Model и View (`GameVM`, `LevelEditorVM` и др.)

### Привязка данных (Data Binding)
- Двусторонняя привязка для свойств ViewModel
- Команды для обработки действий пользователя
- `INotifyPropertyChanged` для автоматического обновления UI

### База данных
- Entity Framework Core (Code First)
- Автоматическое создание базы данных при первом запуске
- Каскадное удаление записей при удалении уровня

---

## Система рекордов

- Фиксируется количество ходов и время прохождения
- Для каждого игрока хранится лучший результат на каждом уровне
- При улучшении результата старый рекорд заменяется
- Общая таблица рекордов показывает лучшие результаты всех игроков

---

## Редактор уровней

- Визуальное создание и редактирование уровней
- Изменение размера поля
- Сохранение новых уровней в базу данных
- Редактирование только пользовательских уровней (стандартные защищены)
- Валидация карты (обязательное наличие игрока)

---

## Запуск проекта

1. Убедитесь, что установлен SQL Server (LocalDB или полноценный)
2. Настройте строку подключения в `SokobanDbContext.cs`
3. Соберите проект (пакеты NuGet: `Microsoft.EntityFrameworkCore.SqlServer`)
4. Запустите приложение

При первом запуске база данных создастся автоматически с 8 стандартными уровнями.
